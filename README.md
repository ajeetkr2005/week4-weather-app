# 🌦️ Weather App
A simple and responsive Weather Application that shows real-time weather information using a public API.


## 🚀 Features
- Search any city weather
- Real-time temperature updates
- Weather conditions (sunny, cloudy, rain, etc.)
- Responsive UI for mobile and desktop
- Clean and modern design

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- Weather API (OpenWeather / any API you use)
